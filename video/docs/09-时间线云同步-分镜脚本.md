# 视频九《时间线云同步》分镜与脚本设计

> 状态：待制作。目标产物 `out/09-timeline-sync.mp4`。
> 规格沿用前八期：Remotion，1920×1080，30fps；窗口设计稿坐标系 1920×1200（scene.ts）。

## 1. 定位与卖点

| 项 | 内容 |
|---|---|
| 观众 | 已在使用 AIShell 的用户（看过或没看过前八期均可独立理解） |
| 一句话 | 你在客户端的每一步操作自动记入时间线，脱敏后同步上云，网页端跨项目统一检索 |
| 核心卖点 | ① 自动留痕（9 类事件零操作）；② 标签与选区（打标即划定时间段）；③ 脱敏上云、默认开启、可一键关；④ 网页端跨项目统一时间线；⑤ 数据可一键清空，本机不受影响 |
| 时长 | 约 120 s（3600 帧，与第八段一致） |
| 不演示 | 登录/初始化（第八段已演）、配额超限（413）、限流退避——叠加层文字提一句即可，不占剧情 |

### 与前八段的关系

- 第八段讲「配置与文件」上云；本片讲「操作记录」上云，是云能力的第二块拼图。
- 本地时间线页（TimelineTab）与标签功能此前未在视频中出现，本片 A/B 幕顺带完成首演。
- 云平台网页端工作台首次出镜（D 幕），需要新绘浏览器窗口场景。

### 叠加层（NOTES9）

1. **C2（1910–2180，info）「三层开关」**
   已登录云服务 + 平台已开通时间线同步 + 本机开关打开——三者同时满足才上传；任一不满足只写本地文件，不排队、不上传。
2. **C2（1990–2200，info）「脱敏后上云」**
   上传前对摘要与详情做凭据形态替换：`password=order@2026` → `password=***已脱敏***`。本地时间线文件保持原样；脱敏是尽力而为的形态匹配，敏感信息请以治理措施兜底。
3. **E3（3720–3890，info）「保留与配额」**
   云端事件默认保留 90 天（按事件时间清理，标签随锚点过期）；单用户上限 200,000 条，超限自动暂停上传，删除云端时间线后即可恢复。

### FeatureCard（F2）

- **自动记录**：SSH、命令、传输、AI 会话，9 类事件零操作留痕
- **脱敏同步**：本机脱敏后上传，默认开启、一键可关
- **跨项目检索**：网页端统一时间线，项目/类别/标签/关键词任意筛

### 复用与新增组件

- 复用：`AppWindow` / `TopBar` / `Cursor`（含 CLICKS 涟漪）/ `Caption` / `Highlight` / `anim.ts` 的 Stop 插值。
- `Note` 叠加层目前散落在各段 script 里，本期抽到 `components/Note.tsx` 共用（info/alert 两态，右缘滑入）。
- 新增 `Web9.tsx` 浏览器框：参考第五段 browser5 的网页绘制经验，但是「访问外部云平台」而非内置浏览器，用普通浏览器 chrome（标签页 + 地址栏），避免与产品内置浏览器混淆。**网页端整页浅色主题**，配色/结构对照 aishell-cloud `web/admin`（UserWorkspace + TimelinePanel + TimelineStream + styles.css），不复用客户端暗色 C 调色板。
- 活动栏/标签页的时间线图标用主仓 `timeline` 图标（两点一线），theme.ts 另补 `clock/box/send/external` 供网页端侧栏。

### 状态机（wbAt/webAt 推导要点）

- 页面态：workbench（终端 ⇄ 时间线标签页 tlT 交叉淡化）⇄ settings（pageT）；时间线标签页在入口点击（ACT_CLICK）后才 `tlOpen`。
