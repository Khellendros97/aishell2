# 视频十《仪表盘与备忘录》分镜与脚本设计

> 状态：待制作。目标产物 `out/10-dashboard.mp4`。
> 规格沿用前九期：Remotion，1920×1080，30fps；窗口设计稿坐标系 1920×1200（scene.ts）。
> 承接第八/九段：同账号已登录、云同步已初始化，本片不演示登录与初始化流程。

## 1. 定位与卖点

| 项 | 内容 |
|---|---|
| 观众 | 已在使用 AIShell 的用户（独立可懂；看过第八段云同步者更有共鸣） |
| 一句话 | 仪表盘是每个项目的「首页」：备忘录随手记密码/IP 等关键信息并加密上云，监控面板和图表让 AI 一句话定制 |
| 核心卖点 | ① 备忘录组件固定置顶：可编辑表格（账号/密码/IP）+ 备忘文本，失焦即保存、一键复制；② 备忘录随仪表盘端到端加密云同步（dashboard.py/memo.md/table.json 三文件）；③ 「定制仪表盘」：描述需求，AI 改 dashboard.py 自动调试验证；④ SDK 数据库管道：凭据代管 + 命令白名单，图表组件直连库查询；⑤ 设置-外观「菜单栏默认打开」：进工作台第一眼就是仪表盘 |
| 时长 | 约 144 s（4320 帧，与第九段一致） |
| 不演示 | 登录/云同步初始化（第八段已演）、换机完整恢复流程（第八段已演，一句带过）、仪表盘脚本 60 秒超时报错、echarts option 非法兜底 |

### 与前几段的关系

- 第八段讲「配置与文件」上云，本片补上演示：仪表盘与备忘录已纳入同一加密同步通道（账号页「配置同步规模」有「仪表盘」计数）。
- 侧栏「仪表盘」面板（活动栏第一个图标，compass）此前未在视频中出镜，本片 A 幕完成首演。
- 「定制仪表盘」走 AI 会话，是第四段（AI 模式）之后 AI 能力的又一次主场景展示：工具条序列 read/write/dashboard_reload/dashboard_view。

### 叠加层（NOTES10）

1. **B2（1310–1610，info）「三个文件，加密上云」**
   仪表盘同步 = `dashboard.py`（定制脚本）、`memo.md`（备忘文本）、`table.json`（备忘表格）三个文件；与笔记同一加密同步通道——内容经凭据保险箱钥匙端到端加密后才上传，服务端只存密文。
2. **D2（2850–3130，info）「数据库管道」**
   图表组件的数据来自 SDK 数据库管道：`db.connections` 列出服务器上启用中的连接（MySQL / PostgreSQL / ClickHouse / Redis），`db.query` 执行单条命令——连接凭据由系统钥匙串代管、命令首词白名单默认只读，脚本拿不到任何密码。

### FeatureCard（F2）

- **备忘录随手记**：密码、IP、入口链接，表格+文本双区，失焦即存、一键复制
- **AI 一句话定制**：监控表格、数据库图表，描述需求即可，AI 改脚本自动验证
- **加密同步上云**：三个文件端到端加密，换机登录即恢复

### 制作注意（前几期踩坑沉淀）

1. 写完立即 `npx tsc --noEmit`（video/ 目录有自己的 tsconfig）。
2. 表格行、工具条、事件列表等流式内容**不做动态锚点推导**，全部绝对定位写死在 layout.ts；需要逐字/逐行定位时用校正层 + `nowrap`。
3. 相机每幕内必须有 hold stop（同一值连续两个关键帧），禁止运动中出指针点击。
