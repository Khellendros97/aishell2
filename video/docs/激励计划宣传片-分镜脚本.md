# 激励计划宣传片《做任务，得积分》分镜与脚本设计

> 状态：已制作完成。目标产物 `out/incentive-promo.mp4`（实测 75.05 s / 1920×1080 / 30fps / 含音轨 / 24 MB）。
> 合成 id：`IncentivePromo`（`video/src/Root.tsx`）。
> 与教学视频（01–09）不同：本片是**宣传片**——节奏更快、动效更猛（弹簧入场、渐变大字、辉光球 + 光束 + 粒子、数字滚动），
> 每幕按 **120 BPM（15 帧/拍）** 卡点，便于替换正式配乐。仍沿用「HTML/CSS 确定性还原 + 摄像机推拉」的既有形态，无真实录屏。

**渠道幕统一节奏（每幕 210 帧）**：章节分隔卡（大号编号 + 渠道名 + 分值，约 60 帧）→ 悬浮窗弹簧入场 →
指针悬停 → 高亮环呼吸 → 点击涟漪 → 结果动效 → 分值结算卡弹出 → 窗口淡出。转入下一渠道前留出 16 帧黑场过渡缓冲。

节奏原则（沿用教学视频教训）：每幕相机到位后 **hold 停稳**再出指针；toast/进度条等关键信息放窗口低位（y≈窗口底部）避免被字幕遮挡；
章节分隔卡必须等上一幕窗口**完全淡出**再入场（`IncentivePromo.tsx` 里用 `prevOut = S - CH_LEN + outAt + 16` 计算）。

### 摄像机模型

窗口按**主仓真实尺寸 1440×900**（`tauri.conf.json` 默认窗口）绘制，整体等比缩放到 `SCALE=0.78`
（外框 1123×702，居中偏上，上下留出章节标/结算卡/字幕带）。相机只做**居中缩放**：
`transform: translate(960 - WIN_C.x*s, 540 - WIN_C.y*s) scale(s)`——即始终取景窗口中心、不平移，
避免为顶部/边缘控件大幅平移把窗口推出画面（这是沿用的返工教训）。
热区坐标定义在窗口内部真实像素（与真实控件一致），经 `toStage` 换算成视频坐标后供高亮环/指针/点击涟漪使用。

### 动效规范

- 弹簧统一用 Remotion `spring({ frame, fps: 30, config })`；缓动曲线沿用 `anim.ts` 的 `EASE`
- 背景：`radial-gradient` 深底 + 3 个 sin/cos 漂移的辉光球 + 7 条斜向移动光束 + 粒子（全部 frame 驱动，确定性）
- 数字滚动：`interpolate` + `Easing.out(Easing.cubic)`，千分位
- 视觉安全：渐变文字用 `whiteSpace: nowrap`；界面热区全部绝对定位；字幕（bottom 64）与结算卡（y≈884）分层不叠

### 音轨

- `video/public/audio/bgm-placeholder.mp3`：**静音**占位音轨（75 s，48kHz 立体声，用工程自带
  `node_modules/@remotion/compositor-win32-x64-msvc/ffmpeg.exe` 的 `anullsrc` 生成）。
- 装配器以 `<Audio src={staticFile('audio/bgm-placeholder.mp3')} volume={0.001} />` 接入——
  **替换正式配乐时直接覆盖同名文件即可，无需改代码**；所有镜头/动效切点已按 15 帧（120BPM）对齐。

### 复用（未改动）

`components/Caption.tsx`、`Cursor.tsx`、`Highlight.tsx`、`Note.tsx`、`ui.tsx`（`Icon`/`Logo`）、
`anim.ts`（`track1`/`EASE`/`Stop`）、`theme.ts`（`C`/`FONT_UI`/`FONT_MONO`）。
`theme.ts` 的 `ICONS` 新增了 `ticket`/`trophy`/`coins`/`flame` 四个图标（从主仓 `src/icons.ts` 照抄，仅新增键）。
