## 2. 新增功能

### 2.1 项目时间线

把项目内的关键活动统一记录成时间线，集中浏览、检索与回溯。

- **统一记录**：SSH 连接建立 / 断开 / 连接失败、`ssh_exec` 命令、SFTP 手动传输完成、
  AI 动作（`run_command`、SFTP 批量、工具调用）、AI 用户提问与回答、终端命令区块定稿，
  都写入项目时间线。
- **存储**：项目级 JSONL 按天滚动，落在 `<项目>/.aishell/timeline/`，默认保留 30 天
  （每天首次写入时惰性清理过期数据）。
- **时间线标签页**：关键词 / 类别 chips / 时间段预设筛选，行可展开查看详情，5 秒轮询刷新，
  入口在活动栏。
- **AI 检索与分析**：新增只读工具 `timeline_search`（三档模式），AI 助手可按时间线检索；
  「AI 分析」按钮把分析任务注入 AI 面板。
- **ask 多选**：`ask` 工具支持 `multi=true` 多选勾选（如产物清单挑选），产物保存复用既有
  `write` 工具的笔记 / 技能目录白名单。

### 2.2 时间线标签与选区

- **选区着色**：对时间线选区打单标签或标签对；同名标签按锚点时间相邻配对，划定闭区间选区，
  行底色区分「直接打标」与「处于标签选区内」两种状态。
- **搜索**：关键词支持 `#标签名` token（可多个，多个之间为 AND，也能与文本混用）；
  搜索框下方列出已有标签 chips，点击即切换筛选。
- **右键操作**：新建 / 更新标签（名称 + 8 色调色板，选已有名称沿用其最新颜色）；
  选区已闭合时询问「创建新标签」还是「更新闭合位置」（`tag_reclose` 移动闭合端并沿用原色）；
  直接打标的行可删除标签。
- **AI 分析范围**：分析前先弹标签多选圈定范围，指令限定按 `#标签名` + 时间区间检索、禁止全量分析；
  未选中任何标签时保持原有全量分析。
- **存储**：标签存项目 sidecar `tags.jsonl`，采用同步直写（不走写线程，避免 rename 后旧句柄写幽灵文件）。

### 2.3 时间线云同步（云服务版）

对接云端 `/api/timeline/*`（协议见 `docs/AIShell云服务-时间线云同步API文档.md`），
把项目时间线脱敏后增量上传，供云平台跨项目统一时间线（工作台页 / 管理后台页）展示。

- **三层开启判定**：已登录 **且** 平台能力 `capabilities.timelineSync` **且** 本机设置开关
  （默认开启，不进配置云同步白名单）；设置页新增「时间线云同步」区块，含开关、状态行与
  「删除云端时间线」（二次确认）。
- **上报实现**：60 秒周期「重读本地 JSONL」上传，无内存队列——埋点主路径不受网络影响、
  崩溃零丢失；游标落在 `config_dir/timeline-sync-state.json`。
- **增量游标**：复合游标 `(lastTs, lastId)`，解决同毫秒事件成组时批次边界落在组内导致
  反复重读、新事件永不上传的问题；存量条目用补算 id 比较。
- **长度口径**：服务端一律按 rune 计数（summary 512 / detail 4096 / projectName 128 / tagName 64），
  客户端新增 `clip_runes` 与 `sanitize_tags` 吸收本地字素口径差异，避免单条超限导致整批永久 400。
- **事件 id**：写入时生成 uuid v4；存量条目补算 `sha256(projectId+ts+kind+summary)` 前 32 hex，
  实现跨设备同 id、服务端 `(user_id, event_id)` 幂等去重。
- **标签同步**：本地增删改置脏标记，tick 按项目 PUT 全量覆盖；首次上传推基线。
- **配额与错误分流**：413 `QUOTA_EXCEEDED` 置持久标记暂停上报（云端清除后复位）；
  403 / 429 / 400 按稳定错误码分流。
- **skill 事件**：`read` 读到 `<name>/SKILL.md` 记为技能事件，标签锚点白名单补充 `skill`
  （依赖服务端迁移 0016）；AI 检索类别说明同步。

### 2.4 员工激励计划对接（云服务版）

- **技能上传登记计分**：SkillHub 技能上传成功后自动登记计分——上传动作开始即武装观察器，
  轮询 `browser_publish_state`（SkillHub 为 SPA，`pushState` 跳转不触发 `on_page_load`，
  故不使用 url 事件），页面落到技能列表页即登记；namespace 从发布页 `#namespace` 下拉采样；
  技能卡片另加奖杯图标可手动补登记兜底。
- **笔记发布工单日志**：右键菜单 + 笔记顶栏双入口，弹出表单预填笔记正文，支持附件与工单号，
  以 multipart 提交（后端 `cloud.rs::incentive_submit_ticket_report`）；工单附件复用用户反馈的
  类型 / 大小白名单校验。
- **账号页「激励计划」**：计分规则 + 本人积分明细 + 全员排行榜（20 秒轮询，页面隐藏时不打扰），
  点排行榜行可查看该成员明细。
- **能力位**：`capabilities.incentive`，为 `false` 时隐藏全部入口（接口会返回 403）。
  后端新增 6 个命令（规则 / 本人积分 / 他人积分 / 排行榜 / 技能登记 / 工单提交）。

### 2.5 终端能力

- **会话结束提示条**：进程退出或建连失败后在终端底部浮出提示条（对照 MobaXterm Session stopped），
  提供 `Enter` 关闭标签页 / `R` 重新连接 / `S` 导出终端输出三个动作，快捷键与按钮双入口。
- **终端输出导出**：新增 `term_export` 命令——父目录自动创建、允许覆盖（save 对话框已确认），
  导出内容为全量 scrollback 纯文本，默认落 `<项目>/.aishell/record/<名>-<时间戳>.log`；
  右键菜单新增「导出终端输出…」入口，会话运行中亦可导出。
- **自动录制终端**：设置 - 功能特性新增开关（**默认关闭**）。开启后每个终端会话（SSH / 本地）
  建连成功后自动开始录制输出，失败只留日志不弹框、不覆盖用户手动开启的录制；仅影响此后
  新建 / 重连的会话。

### 2.6 程序关闭二次确认

AI 助手任务尚未结束时拦截关窗并弹确认框（danger「仍然关闭」），避免误中断进行中的任务。
覆盖全部常驻项目上下文（含后台保活会话与欢迎页任务）；确认后走 `destroy()` 强制关闭，
后端 `Destroyed` 钩子（`ai.kill_all` / 录制收尾）照常执行。

## 3. 改进

- **yolo 全自动模式审批简化**：仅极高风险操作转人工确认，`unbounded` 不再直接拒绝。
  极高风险识别（宁缺勿滥）覆盖递归删除目录树、格式化、裸设备写入、关机重启、`find` 批量删除，
  以及本地 `delete_path` 目标为目录的情况；yolo 跳过 LLM 智能审批判定，高风险直接转人工卡并标注原因。
  `agent` / `suggest` 行为不变。
- **时间线事件优化**：`read SKILL.md` 解析为技能事件；去除 AI 执行命令事件（已由 AI 工具事件覆盖，
  主机信息并入摘要）；AI 提问摘要跳过头部 `[当前工作区域: …]` 注入行后压平。
- **录制收尾兜底**：关闭程序时补写「录制结束（程序退出）」结束行并 flush（此前 webview 消亡后
  React 清理不执行，缓冲丢失）；关闭标签竞态改走 `finish_record` 补写「录制结束（终端已关闭）」，
  `remove` 幂等保证结束行不双写。
- **界面细节**：发布工单日志按钮改用新的品牌渐变配色（与 Skill Hub 一致）；新增图标若干。

## 4. 修复

- **命令收藏编辑所属目录不生效**：下拉候选选中改走原型链原生 value setter——React 受控 input
  会覆写实例 value 并维护 tracker，直接赋值后派发事件被判定「值未变化」而不触发 `onChange`。
  同时命令卡片支持拖拽到分组标题以改所属目录（含未分类分组，交互照欢迎页项目卡片）。
- **重连吞事件标志**：仅旧会话仍在线时才置 `ignoreExit`；原先无条件置位会把新会话首个退出事件
  误当旧事件吞掉，表现为重连后再次退出不弹结束提示条。
- **审批卡无按钮**：审批事件无条件置 `approving`（此前 yolo 下先置 `running` 会被保留，
  按钮只在 `approving` 态渲染）。
- **自动录制接线隐患**：`establish` 重连时调用 `resetRecordingState` 复位录制 UI 标志，
  避免旧会话录制器随 `term_close` 被后端释放后前端 `recording` 残留 `true`、
  导致按钮态错误且自动录制被误跳过。

## 5. 云服务对接变更

- 新增能力位：`capabilities.incentive`（员工激励计划）、`capabilities.timelineSync`（时间线云同步，复用既有能力位）。
- 新增云端接口对接：`/api/timeline/*`（时间线增量上报 + 标签全量覆盖 + 云端清除）、
  激励计划 6 接口（规则 / 积分 / 排行榜 / 技能登记 / 工单提交）。
- 时间线标签锚点 `anchor_kind` 白名单补充 `skill`（服务端迁移 0016 起生效）——
  漏一类会让打在技能事件上的标签被静默剔除且不报错，客户端已补断言锁定该契约。

## 7. 已知限制与待验证项

- **时间线云同步端到端未完成真机验证**：开发时本机无 Postgres，端到端链路
  （登录 → 客户端上报 → 网页端可见）待具备服务端环境后验证。
- **技能事件依赖服务端迁移**：时间线 `skill` 锚点需服务端迁移 0016 及之后版本；旧服务端会静默剔除该标签。
- **激励计划依赖能力位**：未开放 `capabilities.incentive` 时入口全部隐藏，接口返回 403。
- **云更新上传**：CI `publish-update` 任务上传 Windows 大体积制品（约 113 MB）存在上行超时
  （curl 28），本次 `v1.1.4` 由手动兜底上传。

## 8. 升级说明

- 新增设置项均为兼容处理，旧配置无需迁移：
  - `autoRecordTerminal`（自动录制终端）—— 旧配置无此字段按**关闭**；
  - `timelineSyncEnabled`（时间线云同步）—— 旧配置无此字段按**开启**（仍需登录且平台开放能力）。
- 时间线数据按项目落在 `.aishell/timeline/`，保留 30 天，不随项目目录迁移自动搬移。
- 终端录制日志默认落在项目目录 `.aishell/record/` 下。
- macOS 版为 Developer ID 签名 + 公证构建；Windows 未做 Authenticode 签名，
  首次运行可能被 SmartScreen 拦截（点「更多信息 → 仍要运行」）。
