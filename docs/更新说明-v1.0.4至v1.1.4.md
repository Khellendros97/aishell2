# AIShell 更新说明（v1.0.4 → v1.1.4）

## 新增功能

**项目时间线** — 自动记录项目里的关键操作：SSH 连接、执行的命令、文件传输、AI 问答与工具调用。在时间线标签页按关键词、类型、时间段查看，也可以让 AI 助手检索和分析。

**时间线标签** — 给时间线内容打标签并高亮选区，支持 `#标签名` 搜索；打标后可让 AI 只分析选定范围。

**时间线云同步**（需登录公司账号）— 把项目时间线加密脱敏后同步到云端，在网页端跨设备查看统一时间线。设置页可开关，也可一键清除云端数据。

**员工激励计划**（需平台开通）— 技能上传后自动登记计分（可手动补登记）；笔记可一键发布为工单日志（支持附件与工单号）；账号页新增「激励计划」查看计分规则、本人明细与全员排行榜。

**终端会话结束提示条** — 终端退出或建连失败时，底部出现提示条，可一键关闭标签、重新连接或导出输出。

**终端输出导出** — 把终端全部历史输出导出为纯文本，默认保存在项目目录。运行中也支持从右键菜单导出。

**自动录制终端**（默认关闭）— 在「设置 → 功能特性」开启后，每个终端会话自动开始录制输出到项目目录，可随时手动停止。

**关闭程序二次确认** — AI 助手还在工作时关闭程序会先弹确认框，避免误中断正在进行的任务。

## 改进

- 全自动（yolo）模式审批简化：只有极高风险操作（递归删目录、格式化、关机重启等）才转人工确认，不再直接拒绝。
- 命令收藏可直接拖拽卡片移动到其他分组；修复了编辑收藏时切换所属目录不生效的问题。

## 修复

- 修复终端重连后再次退出不弹出结束提示条。
- 修复录制文件在关闭程序或关闭标签时缺少结束标记。
- 修复自动审批下审批卡片不显示按钮。

## 升级说明

- 旧版配置无需迁移，可直接覆盖安装。
- 新增的两项开关均按「不影响既有行为」的默认值处理：自动录制终端默认关闭，时间线云同步默认开启（仍需登录且平台开通）。
- macOS 版已签名并公证，可直接打开；Windows 版未做代码签名，首次运行如被 SmartScreen 拦截，点「更多信息 → 仍要运行」。
